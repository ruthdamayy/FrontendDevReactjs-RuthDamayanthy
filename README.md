# FrontendDevReactjs-RuthDamayanthy

Halaman daftar restoran dengan React.

## Tech Stack

- React: 19
- Node.js: v24.15.0
- npm: 11.12.1

## Fitur

- Login sederhana
- Daftar restoran dengan tampilan grid
- Filter Open Now
- Filter Price
- Filter Categories/Cuisines
- Clear All filter
- Load More
- Detail view restoran
- Review list
- Responsive layout

## Cara Menjalankan Project

Install dependencies:

```bash
npm install
```

Jalankan development server:

```bash
npm run dev
```

Build untuk production:

```bash
npm run build
```

Preview hasil build:

```bash
npm run preview
```
